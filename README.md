# Blokjes

A few sums a day with blocks: a daily visual maths practice tool (addition, subtraction, times and sharing) that moves from building with blocks, to picturing them, to just numbers.

https://keepitterron.github.io/blokjes/

```bash
npm install
npm run dev
```

See [CLAUDE.md](CLAUDE.md) for the stack and layout and [docs/handoff.md](docs/handoff.md) for the full design.
